# Commercial Multifamily Investing — A Plain-English Field Guide

An investor-education guide from Ground Floor Industries. It explains what the documents in a commercial multifamily deal mean, why the numbers matter and which questions uncover the risk.

**Live site:** https://johnlyon-groundfloorindustries.github.io/REI-Education/

## What is in it

- **19 chapters**, from "you are buying a business" through the rent roll, the T12, debt, returns, partnerships and the waterfall, to a repeatable review workflow.
- **Worked examples** with fictional numbers.
- **An interactive operating stress test** (Chapter 15) for trying the numbers yourself.
- **A reusable review checklist and notes.** Progress and notes are saved in the reader's browser when supported and are never sent to a server. Notes can be downloaded as a text file.
- **Concept search, a glossary and a print / save as PDF button.**

## Viewing and updating

No installation or build step. Use the live site, or open `index.html` in a browser.

The site is published with GitHub Pages from the root of the `main` branch. A push to `main` updates it within a minute or two.

## Disclaimer

Educational examples, not a property recommendation. All numerical examples are fictional, and original deal documents and resident information are not included. The guide was prepared October 8, 2026; rules, loan programs and contract terms can change, so confirm the terms that apply to each transaction. Legal and tax questions need the actual agreements and a qualified professional.
