# Commercial Multifamily Investing Guide

A plain-English educational guide by Ground Floor Industries.

## Files
- `index.html`: complete guide, with styling and interactive features included.
- `.nojekyll`: supports serving this as a plain static site.

## Upload
1. Extract this ZIP on your computer.
2. Upload the extracted files to the root of your GitHub repository, rather than uploading the ZIP itself.
3. Commit the files.

Open `index.html` in a browser to read the guide locally. No installation or build step is required. It can also be served by GitHub Pages or another static host.

Includes searchable chapters, fictional worked examples, an interactive operating stress test, a review checklist and downloadable notes. Checklist progress and notes are stored in the reader's browser when supported; they are not sent to a server.

All numerical examples are educational and fictional. Original deal documents and resident information are not included.
